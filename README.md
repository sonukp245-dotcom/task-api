# Task API

A simple CRUD API built with Node.js and Express for managing a to-do task list.

## Features

- Create tasks
- Read all tasks
- Read a single task
- Update tasks
- Delete tasks
- Input validation
- Health check endpoint
- Interactive Swagger UI documentation
- In-memory data storage
